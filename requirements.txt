# Chorus's dependencies live in `pyproject.toml`, because they have to be splittable: this file
# cannot say "stripe belongs to ophan", and per-tekton extras are the point (`agience-chorus[ophan]`).
#
# Installing this file installs the package with every tekton's extras, which is what a developer
# checkout and CI both want. A deployment that runs a subset installs that subset instead:
#
#     pip install "agience-chorus[iris,seraph]"      # no Stripe, no HuggingFace datasets, no numpy
#     pip install -e ".[all,dev]"                    # a full checkout, with the test tools
#
# Restating the versions here would be the fork this indirection exists to avoid.
-e .[all]
